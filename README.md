Sou técnico em Desenvolvimento de Sistemas e, atualmente, curso Análise e Desenvolvimento de Sistemas (ADS). Venho construindo minha experiência através de estudos práticos, laboratórios de código e resolução de problemas reais.

Meu objetivo é continuar evoluindo como desenvolvedor e construir uma base cada vez mais sólida em Engenharia de Software, Python, C e arquitetura de sistemas.
